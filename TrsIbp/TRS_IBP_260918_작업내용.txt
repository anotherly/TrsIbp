TRS IBP 일반사용자 2026-09-18 기능 확장본

[DB]
- 적용 SQL: src/main/resources/db/migration/20260918_ibp_enhancements.sql
- 별도 제공: TRS_IBP_DB_변경_260918.sql
- MariaDB 10.6 기준

[반영 내용]
1. 대시보드 캘린더
   - 우측 일정 카드 클릭: 기존 상세/수정 모달
   - 화살표 클릭: 하단 상세영역에 장소/작성자/상세내용 표시
   - 기존 '오늘의 부서원 상태 공유' 영역을 상세영역으로 변경

2. 일반사용자 프로젝트 관리/권한
   - 기본 USER는 biz_mnpw에 본인이 투입된 프로젝트만 조회
   - 등록/수정/삭제 권한을 추가로 받아도 SELF 범위는 본인 참여 프로젝트로 유지
   - MANAGER/ADMIN은 회사 전체 데이터 범위
   - 회사별 역할/메뉴 권한 테이블(co_authrt_*) 적용
   - 사용자 등록/수정 권한 목록도 회사별 역할을 사용
   - 대시보드는 로그인 사용자에게 권한검사 없이 개방

3. 비용 청구
   - 내 업무 > 비용 청구 추가
   - 프로젝트/비용구분/결제수단/사용일/금액/사용처/비고 등록
   - 영수증/매출전표 이미지/PDF 다중 첨부
   - 등록 즉시 biz_cst에 반영하여 프로젝트 영업이익 차감
   - 기존 회계관리 목록에 작성자 표시

4. 사용자 C/U/D 작업이력
   - 조회는 기록하지 않음
   - 등록/수정/삭제만 user_action_log 기록
   - 회사/사용자/메뉴/대상/URL/IP/일시 기록

5. 개인업무 프로세스/주간보고
   - 프로젝트별 일간 다건 업무 입력
   - 업무구분/업무내용/진행상태/진행률/이슈·특이사항/익일·차주계획
   - 월~금 주간조회
   - 여러 프로젝트를 한 파일로 묶은 XLSX 다운로드

6. 공지사항
   - 일반 게시판에 회사공지 + 시스템공지 통합 조회
   - 회사공지 등록 권한은 회사별 메뉴권한으로 제어
   - 대시보드 팝업 지원
   - '다시 보지 않음'은 브라우저 localStorage 기준(사이트 데이터 삭제 시 재노출)

7. 사무실 자원공유
   - 경영 관리 > 사무실 자원 관리
   - 유형: 회의실/차량/IT장비/서버/기타
   - 사용방식: 시간예약/대여/할당
   - 부가정보: 키=값 형식으로 유형별 유연 관리
   - 내 업무 > 자원 예약
   - 중복시간 예약 방지
   - 예약 저장/수정/취소 시 schdl_info 캘린더 일정 연계
